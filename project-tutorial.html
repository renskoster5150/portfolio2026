Thai Basil Chicken Tutorial

Tutorial

Project Overview

Role

Tutorial creator, Editor

Timeline

4 weeks

Tools

After Effects

Type

Class Project

Project Description

Created a tutorial video explaining how to cook Thai basil chicken, breaking down the recipe in a clear and visual way so the process is easy to follow from start to finish. Adding fun edits to keep the video engaging

The Process

Filming style

I started with the idea of making the tutorial feel immersive, like you are cooking along with me. I originally wanted it to be fully POV so the viewer would see everything from my perspective in real time.

I tried to figure out a way to shoot it in POV, but I didn’t have the right gear to make it stable or clear enough. Because of that, I moved away from that idea and shot it in a more traditional setup instead.

Editing choices

In editing, I focused on keeping the energy up so it didn’t feel too static. I added a lot of quick cuts, close-ups, and small transitions to make the process more fun to watch and easier to follow.

The voice over is intentionally a bit unenthusiastic. I wanted it to feel more natural and not overproduced, like someone just explaining while cooking instead of performing. It also helps match the simple, instructional tone of the video.
