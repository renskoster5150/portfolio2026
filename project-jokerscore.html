Joker Score

Created an original score for a film scene, with the music carefully timed and shaped to match the visuals and enhance the emotion of the moment.

Project Overview

Role

Audio designer

Timeline

1 day

Tools

Ableton

Type

Class Project

Final version

Project Description

The assignment was to select one of a few scenes from different movies. We decided to do the joker, making a score for the iconic stair scene, without looking up the original scene.

The Process

Starting out

We knew that in the original movie, alot of the tracks have a strong focus on strings to build tension and emotion. That gave us a direction for the overall tone.

Sound choices

Based on that, we chose instruments that could carry a similar heavy and emotional feel. We used a sad-sounding piano for the base, combined with cello and acoustic strings to add depth and tension. We also added an organ to give it a darker, more unsettling layer.

Composition

We built the track around the pacing of the scene, matching key moments with changes in the music. Instead of overcomplicating it, we kept it quite minimal so the emotion comes through clearly and supports what’s happening on screen.
