Joker Score

An original score for the Joker stair scene, written without hearing the original.

role

timeline
1 day
tools
Ableton
type
Class project

the challenge

The assignment was to score a scene from a film. We chose the Joker stair scene and made our own version without looking up the original.

the solution

The original leans on strings for tension, so we built around a sad piano, cello and acoustic strings, with an organ for an unsettling layer. We matched changes in the music to key moments and kept it minimal so the emotion comes through.
